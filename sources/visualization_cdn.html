01. CDN이란?

CDN(Content Delivery Network)은 JavaScript·CSS 파일을 여러 서버에서 빠르게 전달하는 네트워크입니다. 초보자는 라이브러리를 PC에 설치하지 않고 HTML에 <script src="…"> 한 줄을 추가해 사용할 수 있습니다.

가장 작은 HTML

<!doctype html>
<html lang="ko">
<head><meta charset="utf-8"></head>
<body>
  <h1>나의 첫 차트</h1>
  <canvas id="chart"></canvas>
  <script src="https://cdn.jsdelivr.net/npm/chart.js@4.6.1/dist/chart.umd.min.js"></script>
  <script>
    new Chart(document.getElementById('chart'), {
      type:'bar',
      data:{labels:['서울','부산','대구'],datasets:[{label:'사고 건수(예시)',data:[120,70,45]}]}
    });
  </script>
</body></html>
CDN은 도서관, 시각화 라이브러리는 책에 비유할 수 있습니다. “모든 CDN”의 완전한 목록은 무한히 많으므로, 이 자료는 강의에 실제로 유용한 주요 CDN 공급자와 대표 오픈소스 시각화 라이브러리를 포괄합니다.

02. 어떤 라이브러리를 고를까?

Chart.js: 막대 그래프와 필터

최소한의 JavaScript 구조

<canvas id="chart"></canvas>
<select id="filter">
  <option value="all">전체</option>
  <option value="fatal">사망</option>
</select>
<script src="https://cdn.jsdelivr.net/npm/chart.js@4.6.1/dist/chart.umd.min.js"></script>
<script>
const data = {all:[120,95,81],fatal:[3,5,2]};
const chart = new Chart(document.querySelector('#chart'),{
 type:'bar',data:{labels:['A','B','C'],datasets:[{data:data.all}]}
});
document.querySelector('#filter').addEventListener('change',e=>{
 chart.data.datasets[0].data=data[e.target.value];
 chart.update();
});
</script>

05. 교통사고 데이터로 만드는 6가지 기사형 실습

난도기사 질문시각화와 데이터 구조
① 입문어느 연도에 사고가 많았나?Chart.js 막대/선 · year, accidents, deaths
② 입문어떤 사고 유형이 많은가?ECharts Treemap/도넛 · type, count
③ 중급어느 시군구에 사고가 집중됐나?Leaflet GeoJSON 코로플레스 · sgg_code, rate + 경계 GeoJSON
④ 중급사고 지점의 공간 패턴은?Leaflet 마커 클러스터·히트맵 · lat, lon, severity
⑤ 중급시간·요일·사고유형 간 패턴은?ECharts 캘린더 히트맵/행렬 · date, hour, count
⑥ 심화사고 발생부터 결과까지 흐름은?Sankey + Scrollama · source, target, value

공공데이터: 공공데이터포털, TAAS 교통사고분석시스템, SGIS 경계 데이터. 각 데이터셋의 공개 범위·좌표계·다운로드 조건을 확인해야 합니다.

06. AI 바이브코딩 프롬프트

당신은 데이터저널리즘 인터랙티브 기사 개발자입니다.
VS Code에서 실행할 단일 index.html 파일을 만들어주세요.

목표: 교통사고 CSV를 기반으로 독자가 지역·연도·유형을 직접 탐색하는 기사.
기술: 바닐라 HTML/CSS/JavaScript, 라이브러리는 CDN으로 로딩.
① Chart.js: 연도별 사고·사망 추세 및 필터
② ECharts: 사고유형 Treemap와 요일×시간 히트맵
③ Leaflet 1.9.4: GeoJSON 행정구역 지도 + 마커 클러스터
④ DataTables 3: 지역별 검색/정렬/페이지네이션
⑤ Scrollama: 스크롤 구간에 따라 강조하는 차트

데이터 컬럼: year, sgg_code, sgg_name, type, count, deaths, lat, lon
요구사항:
- 모든 CSV 컬럼 검증, 결측값과 중복 처리 방침 주석 기록
- 지역코드 기준으로 GeoJSON과 결합; 결합 실패 지역 수 표시
- 전국 수치 합계와 지역 수치 합계가 일치하는지 검사
- 사고 건수와 인구 10만 명당 발생률을 혼동하지 않도록 단위 표시
- 색상 외 텍스트/범례 제공, 모바일 반응형, 키보드 접근성
- 타일 출처·데이터 출처·기준일·라이선스 표기
- CDN 버전을 고정하고 로딩 오류 메시지를 제공
- 실제 데이터가 없으면 '가상 예시' 명시, 임의 실제 통계 생성 금지
- 실행 방법과 코드 수정 지점을 초보자도 이해하도록 설명
먼저 전체 구조와 필요한 파일 목록을 제안한 뒤 구현하세요.

수업 운영 제안: 8주차 변수·DOM → 9주차 Chart.js·ECharts → 10주차 vis-network·Leaflet·Scrollama. 마지막에는 학생이 데이터 컬럼과 질문만 바꾸어 다른 기사로 확장하게 합니다.

07. 최신 버전·운영 시 주의할 점

  • 2026년 변화: Chart.js 4.6.1이 확인됩니다. DataTables는 2026년 7월 v3 정식 릴리스를 발표했습니다. Leaflet 2.0 beta는 2026년 11월 현재 미리보기 단계이므로 강의 기본 예제는 1.9.4를 사용합니다.
  • 차트 유형 ≠ Chart.js 기본 내장: Treemap, Sankey, Boxplot, Funnel, Geo 차트는 확장 플러그인 또는 ECharts·D3를 활용합니다. 플러그인을 불러오기만 해서는 안 되고 버전별 등록 코드가 필요할 수 있습니다.
  • CSS를 함께 불러오기: Leaflet·DataTables·마커 클러스터 플러그인은 CSS가 필요합니다. 지도 컨테이너에는 반드시 높이를 지정합니다.
  • 의존성 순서: Leaflet → 플러그인, Chart.js → 플러그인. 모듈(ESM)과 전역 스크립트(UMD)를 혼합할 때는 빌드 형식을 확인합니다.
  • 버전 고정: 실무에서는 @latest 또는 버전 없는 CDN을 피하고 테스트한 특정 버전을 고정합니다. HTTP 오류·브라우저 콘솔·CORS를 확인합니다.
  • 지도 출처: OSM 지도 타일은 별도 호스팅 및 사용정책을 따릅니다. OSM 타일 서버를 무제한 무료 서비스처럼 가정하지 말고 출처를 명시합니다.
  • 저널리즘 윤리: 위치 데이터의 개인정보, 인구 보정, 표본 분모, 기초 행정구역 경계 변경, 잘못된 색상 의미를 검토합니다.
