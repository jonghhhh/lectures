# 차세대 한국어 팩트체크 자동화 모델 개발 방향 보고서

**기준선**: 이종혁(2026). 한국어 팩트체크 필요성 탐지 모델 및 RAG 기반 팩트체크 자동화 시스템 개발. 한국언론학보, 70(2), 86-123. [이하 '과거 모델']
**통합 자료**: ① 게재 논문(과거 모델) ② 후속연구 심층보고서(2026.7) ③ 오마이팩트 84건 실측 기록(2026.8) ④ 심사 대응 과정('검증 가치 판단 기준 보완') ⑤ 국내외 최신 연구 검색 리서치(2024~2026)
**작성일**: 2026년 8월 10일

---

## 요약: 한 문단 결론

- 과거 모델은 "탐지→검색→판정" 전 과정을 한국어로 최초 통합하고 JTBC 대비 정확도 78.85%를 달성했으나, 오마이팩트 실측에서 **동일 아키텍처가 6단계 정확일치 40%로 급락**한 사실이 확인됨. 급락의 원인은 프롬프트나 판정 모델이 아니라 (a) 검색의 시점·범위 실패, (b) 모델의 사전학습 지식 의존, (c) 6단계 등급 체계 자체의 재현 불가능성이라는 세 가지 구조적 문제였음. 국제 연구 동향(AVeriTeC 2025 오픈모델 의무화, CheckThat! 2025~2026 수치·시점 주장 특화, 신뢰도 인지 RAG, 인간-AI 협업 요구 연구)도 정확히 이 세 지점을 겨냥하고 있음. 따라서 차세대 모델의 개발 방향은 "판정 모델 교체"가 아니라 **① 증거 수집의 시점 정합성·커버리지 확보, ② 증거 강제 인용(grounding) 구조화, ③ 판정 목표의 재설정(3분류 + 서술형 근거), ④ 오픈모델 병행에 의한 재현성 확보**의 네 축으로 재편되어야 함.

## 1. 기준선 진단: 과거 모델이 이룬 것과 남긴 것

### 1.1 과거 모델의 성취 (출발점으로서의 가치)

- 한국어 최초의 end-to-end 팩트체크 파이프라인 구현: 문장 분리 → KcELECTRA 검증 필요성 탐지 → 다중 소스 웹 검색(DuckDuckGo·위키피디아·Serper.dev) → Gemini-2.5-Flash 판정 → 구조화 출력의 5단계 통합임
- 탐지 모델 성능: 테스트셋 정확도 89.31%, F1 82.65%, 정밀도 92.05%, 재현율 75.00%임
- 제21대 대선 토론회 3회분 3,919문장 실전 적용, 499건(12.7%) 검증 대상 선별임
- JTBC 기자 팩트체크 56건 대비 탐지 재현율 92.86%, 공통 52건 판정 정확도 78.85%, 가중 F1 79.04% 달성임
- 탐지 모델 Hugging Face 공개(jonghhhh/claim_factcheck)로 국내 후속 연구 기반 마련임

### 1.2 논문 자체가 인정한 한계 (내부 진단)

- 판단 유보 43.9%(219건): 문장 단위 처리의 맥락 손실 + 웹 증거 가용성 부족이 원인임
- 대안 LLM 비교 실험 부재: Gemini 단독 사용으로 모델 선택의 타당성 검증이 미흡함
- JTBC 52건이라는 소표본 검증: 주장 유형별 성능의 포괄 평가가 불가능한 규모임
- 후보자별 판정 분포 미분석: 정치적 편향 가능성에 대한 실증 점검 부재임
- 오정보(misinformation)와 허위조작정보(disinformation) 미구분: 발화 의도 추론 기능 부재임
- 텍스트 전용: 이미지·영상 기반 허위정보(딥페이크 등) 검증 불가임
- 사후 분석: 토론 진행 중 실시간 제공 수준 미달임

### 1.3 심사 과정에서 추가로 드러난 쟁점 (외부 진단)

- 검증 가치(check-worthiness) 기준의 실증 불투명성: '검증 가능성'과 '검증 중요성' 두 기준이 CLEF 이진 레이블에 실제로 어떻게 내포됐는지, 기계번역 후에도 유지되는지에 대한 사례 기반 입증 요구가 있었음. 논문은 Hassan et al.(2015)의 CFS/UFS/NFS 사례("He voted against the first Gulf War"=CFS vs "Next Tuesday is Election Day"=UFS)와 한국어 대응 사례("한국 경제 1분기 0.2% 마이너스 성장"=필요 vs "국민 여러분께 감사드립니다"=불필요)로 보완했으나, 근본적으로 **한국 정치 담론의 뉴스 가치(화자 지위, 시의성, 갈등 강도)를 반영한 자체 기준·자체 데이터는 여전히 부재**함
- 판단 유보의 유형 분해: 심사 대응 과정에서 유보 사례가 ① 증거 가용성 부족 ② 인과관계 판단 요구 ③ 수사적 과장/사실 주장 구분 실패 ④ 검증 대상 발언과 입력 문장 불일치의 네 유형으로 정리됐음. 이는 "유보=단일 실패"가 아니라 각각 다른 처방이 필요한 이질적 문제군임을 시사함

## 2. 결정적 증거: 오마이팩트 84건 실측이 뒤집은 가정들

- 실측 개요: 오마이팩트(오마이뉴스) 359건 수집분 중 참:거짓 1:1 균형 84건 표본, 탐지 단계 우회, 정답 매체 배제, 8개 버전(v1~v8) 반복 실험임
- 핵심 결과: 최종 버전 v8 기준 커버리지 91.7%, 6단계 정확일치 40%, 인접 허용 58%, 참/거짓 계열일치 56%(전건 기준)임. **JTBC 비교의 78.85%와의 격차가 곧 차세대 개발의 출발점**임

### 2.1 가정 붕괴 ①: "프롬프트를 다듬으면 판정이 좋아진다" — 틀렸음

- 판정 프롬프트를 5개 버전(v1~v5)에 걸쳐 정교화(판정 근거 서술 강화, 등급 선택 요령, 인용 보도 배제 규칙)했으나 정확도는 잡음 범위(34~38%)에서 정체됨
- 반면 검색을 두 번 수정(시점창 검색 v7 + 열린 웹 보조 검색 v8)하자 커버리지 67%→92%, 정확도 31%→40%로 상승함
- 교훈: **병목은 판정(LLM)이 아니라 검색(증거)임.** 프롬프트 규칙은 증거 풀에 대안 자료가 존재할 때만 작동하며, 증거 품질 문제를 프롬프트로 고치려는 시도는 실패함. 예컨대 "주장 전달 보도는 근거가 아니다"라고 지시해도, 시스템이 물어온 자료가 인용 보도뿐이면 판정이 나아질 수 없음

### 2.2 가정 붕괴 ②: "시스템 성능 = 검색+판정 파이프라인의 성능" — 틀렸음

- 커버리지 계측기(판정과 분리된 별도 LLM 콜)를 붙인 결과, 증거를 전혀 확보하지 못한 28건 중 판정을 시도한 14건의 계열일치가 86%로, 증거를 확보한 56건(60%)보다 오히려 높게 나옴
- 해석: 모델이 증거가 아니라 **사전학습 지식(기억)으로 판정**하고 있었음. "일산화탄소는 물에 녹는다", "WHO 원숭이두창 경고" 같은 건은 Gemini가 이미 아는 사실이었음
- 함의: 과거 모델의 JTBC 대비 78.85%에도 같은 경로가 섞였을 가능성을 배제할 수 없음. 대선 토론회 발언은 광범위하게 보도된 사안이라 모델의 사전지식 안에 있을 확률이 높으며, **측정된 것은 시스템의 검증 능력이 아니라 "Gemini가 아는 것"일 수 있음**
- 대응 실증: "증거 밖 지식 사용 금지" 규칙을 프롬프트 최상단에 배치(v6)하자 내부지식 판정이 14건→6건으로 감소했으나 완전히 차단되지는 않음. 구조적 해법(강제 인용 후처리: 판정 근거로 지목한 자료 번호가 실제 증거에 없으면 유보로 강등)은 미구현 상태로 남아 있음
- 국제 동향과의 정합: Temporal leakage(시간적 정보 누수) 연구(2025~2026)가 정확히 같은 문제를 지적함. 웹 규모 학습 코퍼스가 "예측 대상 결과"를 이미 담고 있어 높은 점수가 능력이 아닌 암기를 반영할 수 있으며, 사전/사후 컷오프 비교와 주장 단위 누수 탐지가 표준 방어로 제안되고 있음

### 2.3 가정 붕괴 ③: "최신 정보 검색이 곧 올바른 검색" — 틀렸음

- 팩트체크의 판정 기준 시점은 **발화 당시**임. 그러나 시스템은 2022년 발언을 2026년 기사로 판정하고 있었음 — 4년 뒤의 정보로 과거를 재단한 것임
- 실측 피해: v5 기준 판정 투입 증거의 62%가 발화 90일 이후 기사, 84건 중 22건은 시점창(-365일~+90일) 안 증거가 전무한 상태로 판정됨
- 구체 사례: "원전 짓는 데 최하 15년 걸린다"(2025.9 발화) 검색 시 2026년 7~8월의 SMR·전기본 기사만 상위에 오름. 정작 필요한 자료("원전 짓는데 15년 걸린다?…실제 원전 공사기간 보니", 발화 다음날 타 매체 검증 기사)는 순위에서 밀려 있었음
- 원인: 네이버 뉴스 API에 기간 파라미터가 없고, 최신순 정렬은 "검색 실행 시점" 기준이라 과거 발언일수록 무관한 최근 기사가 상위를 채움
- 해법 실증: API 상한(100건)까지 넓게 수집 후 클라이언트에서 시점창(-365일~+90일)으로 필터·재배열하는 방식이 시점창 내 증거를 건당 1.85건→4.5건으로 개선함. 윈도우 설계 근거는 뒤로 1년(발화 직전 누적 사실관계 확인), 앞으로 90일(사후 확인 보도 포함, 후일담 배제)임
- 국제 동향과의 정합: ChronoFact(타임라인 기반 시간 검증), TSVer(시계열 증거 검증 벤치마크), CheckThat! 2026 Task 2(수치·시점 주장 검증) 등 **시간 인지(time-aware) 팩트체킹이 독립 연구 영역으로 부상**했으며, 검증 가치 주장의 3분의 1 이상이 수치 주장이라는 통계가 반복 확인되고 있음

### 2.4 가정 붕괴 ④: "증거가 없다 = 검증 불가능한 주장이다" — 82%가 틀렸음

- v5 기준 "증거 부재"로 배제했던 28건을 시점창 검색(v7)과 웹 검색(v8) 도입 후 재확인한 결과, **23건(82%)이 커버로 전환**됨. "7만 원짜리 잼버리 텐트", "WHO 원숭이두창 경고" 등은 당시 여러 매체가 보도한 사안으로, 증거가 없었던 게 아니라 검색이 실패했던 것임
- 교훈: "증거가 없다"는 판정을 내리기 전에 검색을 의심해야 함. 증거 부재를 데이터의 속성으로 귀속시키면 시스템 결함이 영구히 은폐됨. **과거 모델의 판단 유보 43.9% 역시 상당분이 '증거 부재'가 아닌 '검색 실패'였을 가능성이 높음**
- 진짜 검증 불가 영역의 실체: 최종 미커버 7건(8%)은 사진 대조("2년 전 총선 사진 재사용"), 원시 데이터 집계("비례대표-여성의원 비율"), 실물 확인("투표용지 인쇄") 등 **텍스트 검색으로 도달 불가능한 원자료 주장**이었음. 이 영역은 검색 개선으로 좁혀지지 않으며, 별도 경로(이미지 검색·역이미지 탐색, 공공데이터 집계 에이전트) 설계 또는 명시적 범위 제외가 필요함

### 2.5 가정 붕괴 ⑤: "6단계 등급은 자동화의 목표로 유효하다" — 재현 불가능함

- v8 혼동행렬 분석: 양극단은 맞추고('사실' 61%, '거짓' 58%) 중간 등급은 못 맞춤('대체로 사실' 21%, '대체로 거짓' 19%)임. 최대 오류 덩어리는 정답 '대체로 사실'→시스템 '거짓' 10건임
- 오류 10건의 실체: 시스템 판단이 오히려 논리적으로 타당했음. "김포-인천공항 고속전철 10여 분"(실제 37~39분), "대통령 국회 해산권 가진 나라 없다"(프랑스·포르투갈 등 존재), "원전 최하 15년"(신한울 3호기 8년 2개월) — 시스템은 **문자 그대로의 명제**를 검증했고 오마이팩트는 **발화자의 취지**("두 공항이 가깝다")를 인정한 것임
- 결론: 6단계 중간 등급은 검증 결과가 아니라 **편집 판단**을 담고 있음. 취지 인정의 경계는 매체·기자·사안에 따라 달라져 재현 가능한 기준으로 환원되지 않음. "양극단으로 몰지 말라"는 프롬프트 교정(v3)도 라벨 분포만 정답에 근접시키고 판별력은 오히려 하락시켜 실패함
- 이는 과거 모델 논의 절의 문제의식(등급 판정형 vs 서술형 결론의 비교 필요)을 실증으로 확정한 것임: **자동 시스템의 1차 산출은 참/거짓 방향+유보의 3분류 + 근거 자료·판단 이유의 서술이어야 하고, 6단계 세부 등급은 인간 편집자의 최종 결정 영역으로 이관**해야 함

### 2.6 벤치마크 방법론 자체의 교훈 (차기 연구 설계에 직결)

- 정답 누수는 도메인 차단만으로 막히지 않음: 원본 도메인 차단 → 포털 정규화 링크(언론사 코드 047) 우회 → 다음 미러(v.daum.net, 식별자 전무) 우회 → 커뮤니티 전재(제목 변경) 우회의 4중 경로가 실측됨. 최종 해법은 정답 기사 359건 전량의 제목 앞 16자를 정규화해 제목·요약·본문 앞 2000자의 3지점에서 차단하는 방식임. **평가 매체 기사가 포털·커뮤니티로 재유통되는 한국 언론 환경에서 도메인 차단만 쓰는 벤치마크는 신뢰 불가**임. 누수분 계열일치 84.2% vs 무누수분 65.5%로 격차가 실증됨
- 타 매체 팩트체크 기사 유입은 허용하되 명기: 13건 유입분 정확일치 62% vs 나머지 37%로, 시스템이 한 일이 "사실 대조"가 아니라 "남의 결론 인용"에 가까움. 실무적으로는 정당한 자료이므로 허용하되, 유입 건수와 부분집합 정확도를 상시 병기해야 함
- 커버리지와 정확도의 분리 측정: "검색이 사안을 물어왔는가"와 "판정이 맞았는가"는 다른 질문이며, 합산하면 개선 방향을 정할 수 없음
- 계열일치의 이중 기준: 판정 시도분 기준만 보면 유보를 늘리는 변경이 무조건 개선으로 보이는 착시가 발생함(v6이 실례: 시도분 70%이나 전건 46%). 전건 기준(유보=오답)을 반드시 병기해야 함
- 고정 배제 목록의 함정: 검색을 개선하는 실험에서는 개선분이 배제 집합 안에서 발생해 채점표에 안 잡힘. 커버리지가 변하는 실험은 전체 표본 기준을 주 지표로 삼아야 함
- 재현성 기본기: temperature 0.0(기본값 1.0에서는 동일 프롬프트 재실행 간 정확일치가 19→15건까지 흔들려 A/B 자체가 불가), seed 고정, **버전별 프롬프트의 커밋 보존**(v1~v5 원문 유실이 이번 실험 최대의 방법론적 결함)임

## 3. 국내외 최신 연구 동향: 다섯 가지 수렴점

### 3.1 오픈모델·재현성·효율이 평가의 전제 조건이 됨

- AVeriTeC 2025(제8회 FEVER 워크숍): **오픈 가중치 모델만 허용, 단일 GPU(23GB), 주장당 1분 이내**라는 제약을 의무화함. 7개 제출팀 중 6팀이 이 제약 하에서 베이스라인 초과, 우승팀 CTU AIC는 장문맥 RAG 기반 2단계 파이프라인으로 AVeriTeC 점수 33.17% 달성임
- HerO/HerO 2(숭실대 팀 HUMANE): Qwen3·Llama 등 오픈 LLM 무리(herd)로 질의 확장→밀집 검색→증거 요약→질문 생성→판정을 구성해 준우승, 차기 공식 베이스라인으로 채택됨. **한국 연구팀이 오픈모델 팩트체킹의 국제 선두**에 있다는 점에서 협력·비교 대상임
- 함의: 과거 모델의 "Gemini API 단독 + 비교 실험 부재"는 국제 표준에서 이미 뒤처진 조건임. 심층보고서가 제안한 EXAONE(RTX 4090 로컬 구동 가능, 학술 연구 허용 라이선스) 병행 + 3조건 비교(API 단독 / 로컬 단독 / 하이브리드 라우팅)는 이 표준에 대한 직접적 응답임

### 3.2 수치·시점 주장이 독립 태스크로 분화됨

- CheckThat! 2025 Task 3: QuanTemp 데이터셋(전 세계 45개 팩트체크 기관, 15,000+ 주장, 통계·비교·구간·시점 범주) 기반 수치 주장 검증 태스크 신설임. True/False/Conflicting 3분류가 표준임 — 6단계가 아님에 주목
- CheckThat! 2026 Task 2: 수치·시점 주장에 **test-time scaling**(다중 추론 경로 생성 후 최적 경로 재순위화)을 결합하고, 판정 정확도만이 아니라 **추론 과정(reasoning trace)의 품질** 자체를 평가 대상에 포함함
- 함의: 토론회 발언의 상당수가 수치 주장(실업률, GDP, 예산)이므로 수치 주장 하위 분류기 + 전용 검증 경로는 필수임. 단, 오마이팩트 실측에서 KOSIS API 직접 연동은 84건 중 2건에만 투입되어 투자 대비 회수가 낮았음 — **전용 API 확대보다 웹 검색 결과 중 1차 자료 도메인(kosis.kr, index.go.kr, law.go.kr)에 신뢰도 가중을 주는 방식이 비용 대비 효과적**이라는 것이 실측 결론임

### 3.3 증거의 '신뢰도·순서·충돌'이 판정을 좌우함이 실증됨

- 상충 증거 해소: Ge et al.(IJCAI 2025)은 신뢰도가 다른 출처들의 상충 증거 앞에서 검색 증강 LLM의 신뢰성이 크게 저하됨을 보임 — 과거 모델의 유보 다수가 "증거 부족"이 아니라 "충돌 미해소"였을 가능성을 시사함
- 신뢰도 인지 RAG: 출처 권위 기반 동적 가중(Deng et al. 2025 등), LLM의 출처 권위 인식 벤치마크(AuthorityBench 2026), 매체 배경 지식 저장소(Know Your Source 2026)가 잇따라 제안됨. 과거 모델의 정적 화이트리스트(go.kr, ac.kr 우선)에서 **한국 언론사 신뢰도 사전(pre-computed credibility dictionary) 기반 동적 가중**으로의 전환이 요구됨
- 위치 편향: Bernardelle et al.(SIGIR 2026)은 프롬프트 내 증거 배치 순서 자체가 판정에 영향을 미침을 실증함 — 신뢰도 높은 증거를 앞·뒤에 배치하는 재배열만으로 추가 비용 없이 성능 개선이 가능함. 과거 모델의 "검색 결과를 순서대로 나열" 방식은 즉시 교체 대상임
- RAG 오염 방어: Zeng et al.(2025)의 RAGuard(과거 모델도 인용)에 이어, 검색 결과를 액면 신뢰하는 관행이 콘텐츠 공격(attacks-by-content)에 취약함을 지적하는 연구가 이어지고 있음

### 3.4 멀티에이전트 검증·재검토가 표준 아키텍처로 자리잡음

- LoCal(WWW 2025): 분해 에이전트 + 추론 에이전트 + 평가 에이전트 구조로 논리적 동치성 검사와 반사실(counterfactual) 도전 검사를 수행함 — "판정과 근거 설명의 논리적 정합성"을 별도 에이전트가 검토하는 방식임
- Qraft(TACL 2026): 판정을 넘어 **팩트체크 기사 전문(全文) 자동 생성**을 다룸. CheckThat! 2026 Task 3도 전체 팩트체크 기사 생성을 태스크화함 — 산출물의 목표가 "라벨"에서 "근거를 갖춘 서술"로 이동하고 있음을 보여줌
- DebateCV(과거 모델 인용), MERMAID(검증 이력 메모리), 허위정보 라이프사이클 5-에이전트 등 다양한 협업 구조가 경쟁 중임
- 실무적 절충(심층보고서 제안): 전면 5-에이전트가 아니라 기존 파이프라인에 ① 일관성 검토 에이전트(경량 로컬 모델, API 비용 0) ② 유보 재심 에이전트(유보 건에 한해 1층 정부DB·자율 검색 재시도)의 2개만 추가하는 최소 비용 설계가 합리적임. 단, 오마이팩트 실측에서 **재심 단계의 효과가 미측정 상태**(1차 판정을 저장하지 않아 전후 비교 불가)이므로, 차기 실험에서는 1차 판정 기록을 의무화해 재심의 한계 효용을 반드시 계측해야 함

### 3.5 기검증 주장 매칭(PFCR)과 인간-AI 협업이 실무 표준이 됨

- SemEval-2025 Task 7: MultiClaim(39개 언어 20.6만 팩트체크) 기반 기검증 주장 검색이 대규모 태스크화됨. 최고 팀은 단일언어 92% 정확도 달성임 — 이미 검증된 주장은 재검증하지 않고 기존 판정을 재사용(비용 0)하는 선행 단계가 국제 표준 파이프라인에 편입됨
- 한국적 자원: SNU팩트체크가 2024년 운영 중단됐으나 누적 5,000여 건이 읽기 전용으로 공개 유지 중임. 오마이팩트 수집분 359건과 결합하면 **한국어 기검증 주장 DB의 초기 자산**으로 활용 가능함 — 과거 모델에는 전무했던 구성 요소임
- 인간-AI 협업 요구 연구: Warren et al.(CHI 2025) "Show Me the Work"는 전문 팩트체커 인터뷰를 통해 자동화 도구가 제공해야 할 설명의 요건(의사결정 과정과 정렬된 설명, 검증 가능한 출처 제시)을 규명함. Schmitt et al.(2025)은 설명이 체감 유용성은 높이지만 **성능을 일관되게 개선하지 못하며 과신을 유발할 수 있음**을 실증함(n=433) — "설명을 붙이면 좋다"는 소박한 가정이 아니라, 어떤 설명이 기자의 검토를 실제로 돕는지에 대한 실험 설계가 필요함
- 함의: 과거 모델 논의 절의 "하이브리드 모델" 주장이 국제적으로 검증된 방향임이 확인됨. 다만 선언에 그치지 않고, **기자 대상 파일럿(오마이팩트·뉴스톱 등)으로 협업 인터페이스의 효용을 실증하는 단계**로 나아가야 함

## 4. 차세대 모델 개발 방향: 우선순위 로드맵

- 우선순위 판단 기준: (a) 오마이팩트 실측에서 효과가 확인됐는가, (b) 국제 동향과 정합하는가, (c) 비용 대비 성능 개선 폭이 큰가의 세 축임

### P0 — 즉시 반영 (실측으로 효과 확인, 추가 비용 미미)

- **발화 시점창 검색의 전면 채택**: 모든 검색 경로에 발화일 앵커링(-365일~+90일) + 시점창 내 우선 2단 라운드로빈 배치를 표준화함. 실측 근거: 시점창 내 증거 1.85→4.5건/5건, 커버리지 66.7%→76.2%임. 검색 API가 기간 필터를 제공하지 않으면 상한까지 넓게 수집 후 클라이언트 필터링으로 우회함
- **복합 검색(뉴스 API + 열린 웹) 고정 칸 배정**: 상위 5칸 중 2칸을 웹 검색에 고정 배정함. "뉴스가 부족할 때만 웹 발동" 같은 개수 조건은 실패가 실증됨(무관 기사가 칸을 채워 웹이 영영 발동하지 않음) — **개수는 관련성의 대리지표가 못 됨**. 실측 근거: 커버리지 76.2%→91.7%임
- **증거 밖 지식 사용 금지 규칙의 프롬프트 최상단 배치 + 충돌 규칙 제거**: "유보를 남발하지 말라"류의 상충 지시를 함께 제거해야 효과가 발현됨. 실측 근거: 내부지식 판정 14건→6건임
- **신뢰도 기반 증거 재배열**: 검색 결과를 수집 순서가 아니라 신뢰도 점수순으로 재배열해 프롬프트 앞·뒤에 고신뢰 증거를 배치함(위치 편향 연구의 즉시 적용). 추가 비용 0임
- **판정 출력의 필드 순서 고정**: reason → judgment → confidence 순으로 강제해 결론보다 근거를 먼저 생성하게 함. temperature 0.0 고정임

### P1 — 차기 논문의 핵심 기여 (구조 변경, 실험 설계 필요)

- **강제 인용 후처리(grounding enforcement)**: 판정 근거로 지목한 자료 번호가 실제 증거 목록에 없으면 자동으로 유보 강등하는 후처리를 구현함. 내부지식 판정의 잔여분을 구조적으로 차단하는 유일한 방법이며, 미구현 상태로 남은 최우선 과제임. 이 장치가 있어야 보고되는 성능이 "시스템의 검증 능력"이라는 주장이 성립함
- **판정 목표의 재설정**: 1차 산출을 참/거짓 방향+유보 3분류 + 근거 자료·판단 이유 서술로 전환함(v8 기준 3분류 축약 시 65%). 6단계는 인간 편집자 결정 영역으로 이관하고, 벤치마크는 6단계 정확일치·인접 허용·계열일치(전건/시도분)를 병기함. CheckThat! 수치 주장 태스크의 3분류(True/False/Conflicting) 표준과도 정합함. 서술형 결론의 형식은 "~~ 근거가 확인되었으나 최종 판단에는 추가 검증이 필요하다"류로, FactCheck.org의 서술형 모델과 Qraft의 기사 생성 연구를 참조함
- **하이브리드 모델 라우팅 + 3조건 비교 실험**: 명백한 판정(증거-주장 직접 일치)은 로컬 오픈모델(EXAONE 7.8B 등)로 종결, 복합·상충·인과 판단만 API 모델로 이관함. 조건 A(Gemini 단독)/B(로컬 단독, 완전 재현 조건)/C(하이브리드)를 일치도·유보율·건당 비용·건당 시간의 4축으로 비교함 — "대안 모델 비교 부재"라는 심사 지적과 AVeriTeC 2025의 오픈모델 표준에 동시 대응하는 설계임
- **기검증 주장 매칭 선행 단계**: SNU팩트체크 아카이브(5,000여 건, 읽기 전용 공개) + 오마이팩트 수집분(359건) + 뉴스톱 등으로 한국어 기검증 주장 DB를 구축하고, 파이프라인 최전단에서 임베딩 매칭으로 기존 판정 재사용 여부를 판별함. SemEval-2025 Task 7의 방법론(다국어 임베딩 미세조정)을 한국어 단일언어 설정으로 이식함
- **한국 언론사 신뢰도 사전 + 동적 가중**: Mujahid et al.(2025)의 LLM 기반 매체 평가 방법론으로 국내 매체별 신뢰도 점수를 사전 산출하고, 정적 도메인 필터를 신뢰도 가중(정부·공공 1.0 / 주요 언론 0.8 / 기타 언론 0.6 / 일반 웹 0.4, 실측 코드에 기구현)으로 대체함. 주장 전달 보도·예정 보도·재인용 보도를 구분하는 **증거 유형 분류기**(독립 검증 보도 vs 인용 보도)를 신뢰도 축과 별도로 추가함 — 프롬프트 규칙으로는 실패했으므로(v5) 검색·재배열 단계에서 처리함
- **재심 에이전트의 효과 계측**: 1차 판정을 반드시 저장한 뒤 재심(유보 건 재검색 + 일관성 검토) 전후 변화를 측정함. 효과가 비용을 정당화하지 못하면 과감히 축소함

### P2 — 중기 확장 (별도 연구로 분리 가능)

- **한국어 자체 검증 가치 데이터셋 구축**: 기계번역 CLEF 데이터의 한계(심사 지적)를 근본 해소하는 길임. AFaCTA의 LLM 3중 추론 경로 주석 자동화로 비용을 절감하되, 한국 정치 담론의 뉴스 가치 요인(화자의 공적 지위, 시의성, 갈등 강도)을 반영한 자체 기준을 수립함. 오마이팩트 원 출처 링크 348건으로 탐지 통과율(재현율 하한)을 우선 측정해 현 모델의 실전 탐지 성능부터 확정함
- **수사적 과장/취지 판단 모듈**: '대체로 사실'류 불일치의 핵심인 "문자적 명제 vs 발화 취지" 문제를 half-truth 탐지(Tang et al. 2025의 TRACER)와 발화 의도 추론 연구에 연결함. 오정보/허위조작정보 구분(의도 추론)도 이 모듈의 연장선임
- **원자료 대조 경로**: 텍스트 검색 불가 영역(이미지 대조, 원시 데이터 집계, 외신 원문)에 대해 역이미지 검색·공공데이터 집계 에이전트를 별도 설계하거나 명시적 범위 제외를 선언함. AVerImaTeC(이미지-텍스트 주장 검증, 2026)이 국제 벤치마크로 이미 등장함
- **실시간화**: 음성 인식(faster-whisper 등 기보유 파이프라인) 연동 + 처리 속도 최적화(v8의 건당 23.5초 중 대부분이 DDG 지연 — 네이버가 시점창 안에서 충분한 관련 자료를 확보한 경우 웹 생략하는 관련성 기반 조건 필요, 단순 개수 조건은 실패 실증됨)임
- **웹 데모 배포**: HuggingFace Spaces(기존 모델과 동일 허브, Gradio) + DigitalOcean FastAPI 배치 API의 이중 구성으로 심사 대응·논문 각주 명시·언론사 파일럿 채널의 3중 역할을 수행함

## 5. 차기 연구의 평가 방법론 (과거 모델 대비 전면 재설계)

- **이중 벤치마크**: ① 대선 토론회(기존, 시스템 간 종단 비교용) ② 오마이팩트 359건(신규, 참:거짓 균형·발화 시점 분산·정답 라벨 확보) — 시점·장르 일반화를 동시 검증함
- **정답 누수 3중 차단의 표준화**: 도메인 + 네이버 언론사 코드 + 정답 기사 제목 접두(정규화 앞 16자, 제목·요약·본문 앞 2000자 3지점 검사)를 평가 프로토콜에 명문화함. 누수분/무누수분 성능을 분리 보고함
- **4계층 지표 체계**: ① 커버리지(검색이 사안을 물어왔는가, 판정과 분리된 독립 계측) ② 판정 정확도(3분류 계열일치를 주 지표로, 전건 기준·시도분 기준 병기) ③ 근거 충실성(강제 인용 통과율, 인용 자료의 시점창 내 비율) ④ 운영 비용(건당 시간·건당 API 비용)임
- **내부지식 오염 감사**: 증거 미확보 건에서의 판정 시도율과 그 정답률을 상시 보고함 — 이 수치가 낮아야 "증거 기반 시스템"이라는 주장이 성립함
- **재현성 프로토콜**: 각 실험 조건(arm)의 프롬프트 원문 커밋, seed·temperature 고정, 탐지 모델·평가 데이터·프롬프트의 HF 공개, 완전 로컬 조건(조건 B) 결과 병기임

## 6. 차기 논문 프레이밍 제안

### 연구문제 (안)

- RQ1: 발화 시점창 검색과 복합 검색 전략은 증거 커버리지와 판정 유보율을 얼마나 개선하는가 — 그리고 그 개선은 검색 실패로 위장됐던 '증거 부재'를 얼마나 회수하는가
- RQ2: 강제 인용 후처리는 LLM의 사전학습 지식 의존(내부지식 판정)을 구조적으로 차단하며, 이때 보고되는 성능은 증거 기반 검증 능력을 얼마나 순수하게 반영하는가
- RQ3: 3분류+서술형 근거 산출은 6단계 등급 산출 대비 전문 기자 판단과의 일치도·실무 수용성에서 어떤 차이를 보이는가
- RQ4: 하이브리드 라우팅(로컬 오픈모델 + API 모델)은 단일 API 모델 대비 성능-비용-시간-재현성의 4축 트레이드오프에서 어떤 위치를 갖는가

### 예상 기여 포인트

- 이론적 기여: 팩트체크 자동화의 병목이 판정(생성)이 아니라 검색(증거)에 있음을 한국어 실측으로 규명하고, '판단 유보'를 증거 가용성·검색 실패·충돌 미해소·취지 판단의 이질적 문제군으로 분해하는 개념틀 제시임. 알고리즘적 게이트키핑 논의(과거 모델의 이론틀)를 "증거 선별의 시점·신뢰도·순서가 사실성 판정을 규정한다"는 수준으로 구체화함
- 방법론적 기여: 한국 언론 환경(포털 재유통) 특유의 정답 누수 문제와 3중 차단 프로토콜, 커버리지-정확도 분리 측정, 내부지식 오염 감사 등 **한국어 팩트체크 벤치마크 방법론의 표준안** 제시임
- 실무적 기여: 오픈모델 병행·웹 데모·기검증 주장 DB로 재현성과 언론 실무 이전 가능성을 동시 확보함. SNU팩트체크 중단 이후 공백 상태인 한국 팩트체크 인프라에 대한 학술적 대안 제시임

### 서사 구조 (논문 논리 흐름)

- 1막: 과거 모델의 성취(78.85%)와 그 수치의 조건성 — 광범위 보도 사안·소표본·내부지식 오염 가능성임
- 2막: 실전 데이터(오마이팩트) 실측이 드러낸 세 가지 구조적 결함 — 시점 부정합, 지식 의존, 등급 체계의 재현 불가능성임
- 3막: 국제 동향(오픈모델 표준, 시간 인지 검증, 신뢰도 인지 RAG, 3분류 표준)이 같은 결론에 수렴함을 확인임
- 4막: 네 축(시점 정합·강제 인용·판정 재설정·오픈모델 병행)의 개선을 구현하고 이중 벤치마크·4계층 지표로 검증임
- 5막: 하이브리드 협업 모델의 실무 이전 — 서술형 근거 산출과 기자 파일럿임
