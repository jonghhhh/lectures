2-5. 수집 설계 체크포인트

  • 단위 정의: 문서 1건? 조문 1개? 사업 1개? — 분석 단위가 스키마를 결정
  • 식별자 확보: 의안 ID, 법령 ID, 세부사업코드 — 이후 결합의 열쇠
  • 증분 수집: 마지막 수집 시점 이후만 — 매일 갱신의 전제
  • 원자료 보존: API 응답 원본(JSON) 저장 → 가공본 별도 — 재현성의 기본

3-2. BERT 증류: 대량·저비용·재현

조문 비교용 코드북(지원대상·지원수단·전담조직·위원회·예산조항) 초안을 표로.
  • 한계: 코드 실행·파일 처리는 사람이 직접 / 대량 작업 불가

5-3. ② py·js 활용형 — AI가 직접 코드를 짜고 실행

  • 도구: Claude Code, Codex, Gemini CLI 등 에이전트형 코딩 도구, 또는 채팅의 코드 실행 기능
  • 할 수 있는 일: 수집 스크립트 작성·실행, 데이터 정제, 분석, 그래프, HTML 페이지 생성까지 한 흐름
  • 작업 지시 예
1) KOSIS API로 경기도 31개 시군 2015~2025 청년(19~34세) 인구를 수집해 CSV 저장
2) 지방재정365에서 같은 기간 시군별 청년 분야 세출 예산 수집

4) 1인당 청년예산과 청년인구 증감률의 관계를 산점도와 패널 회귀로 분석
5) 결과를 한 장짜리 HTML 보고서로. 인증키는 .env 파일에서 읽을 것

실행 파일로 남기게 하는 프롬프트 (사후 재현성용)

위 작업을 대화창 안에서 바로 계산하지 말고, 단계별 실행 파일로 만든 뒤 실행할 것.
- 01_collect.py   : API 수집, 원본 응답(JSON)을 data/raw/에 날짜별 저장
- 02_clean.py     : 정제·결합, 결과를 data/processed/에 CSV·Parquet로 저장
- 03_analyze.py   : 회귀·그래프, 결과표와 그림을 output/에 저장
- 04_report.js    : output/ 결과로 HTML 보고서 생성 (또는 04_report.py)
- run_all.sh      : 01~04 순서 실행, 어느 단계에서 실패해도 멈추고 원인 출력
- requirements.txt(패키지 버전 고정), config.yaml(기간·지역·엔드포인트), .env(키, 공유 금지)
- logs/에 실행 일시·수집 건수·결측·중복 건수 기록
- README.md에 실행 순서, 입력·출력 파일, 재실행 방법 기술
- 실행 후 수집 건수와 표본 5건을 원문과 대조한 결과 보고
  • 왜 실행 파일인가: 대화 중 계산은 과정이 남지 않음 → 같은 결과를 다시 만들거나, 심사·검증 요청에 답하거나, 기간을 바꿔 재분석할 수 없음
  • 실행 파일 + 원자료 + 버전 고정 = 사후 재현성의 최소 조건 — 공유된 R 스크립트의 약 74%가 재실행에 실패했다는 보고(Trisovic et al., Shah et al. 2026에서 재인용)
  • 스크립트가 있으면 AI 에이전트가 재현·수정도 가능 (AI Coding Agents Can Reproduce Social Science Findings)
  • 연구자의 역할 변화: 코드 작성자 → 작업 설계자·검수자
  • 검수 습관: 수집 건수 확인, 표본 5건 원문 대조, 결측·중복 점검을 AI에게 함께 지시

용어집

API (Application Programming Interface)
프로그램이 다른 시스템의 데이터·기능을 정해진 규칙으로 요청하는 창구. 공공 API는 인증키를 붙여 URL로 호출, JSON·XML로 응답
AX (AI Transformation, AI 전환)
업무 절차·조직·인프라를 AI 활용 전제로 재설계하는 과정. 도구 도입을 넘어 규정·교육·데이터 체계까지 포함
BERT
구글이 2018년 공개한 인코더형 언어모델 계열. 분류·추출에 강하고 수억 파라미터로 작아 내부 서버 구동 가능. RoBERTa·KLUE-RoBERTa 등 파생 모델 다수
BM25
단어 출현 빈도와 문서 길이를 반영하는 고전적 키워드 검색 점수. 고유명사·조문 번호 검색에 강함
CAP (Comparative Agendas Project)
정책 의제를 21개 주요 주제(경제, 보건, 환경 등)로 분류하는 국제 공통 코드북. 법안·연설·언론 비교연구의 표준
청크 (Chunk)
RAG 검색을 위해 긴 문서를 나눈 단위. 너무 짧으면 맥락 단절, 너무 길면 검색 정밀도 저하
CLAUDE.md
Claude Code가 매 세션 시작 시 자동으로 읽는 프로젝트 메모 파일. 연구 목적·변수 정의·폴더 구조·금지사항 기록
코드북 (Codebook)
내용분석 범주의 정의·판단 기준·예시·경계사례를 정리한 문서. 사람 코더와 LLM 프롬프트의 공통 기준
공공의견 (Public Comments)
미국 행정절차에서 규칙안 공고 후 시민·단체·기업이 제출하는 의견. Regulations.gov에 공개, 규제 연구의 대규모 텍스트 자료
cron
리눅스·유닉스의 예약 실행 도구. "매일 07:00 실행" 같은 일정을 한 줄로 지정
도메인 적응 사전학습 (DAPT)
범용 언어모델을 특정 분야(민원·법령 등) 비라벨 말뭉치로 추가 사전학습해 분야 어휘·문체에 맞추는 기법
이중차분 (DID, Difference-in-Differences)
정책 시행 집단과 비시행 집단의 전후 변화 차이를 비교해 정책 효과를 추정하는 준실험 설계
증류 (Knowledge Distillation)
큰 모델(교사)의 판단을 작은 모델(학생)이 학습하게 하는 방법. 여기서는 LLM이 붙인 라벨로 BERT를 학습시키는 방식
임베딩 (Embedding)
문장·문서를 의미를 담은 숫자 벡터로 바꾼 것. 벡터 간 거리로 의미 유사도 계산, 의미검색의 기반
F1 점수
정밀도(맞다고 한 것 중 실제 맞은 비율)와 재현율(실제 맞은 것 중 찾아낸 비율)의 조화평균. 범주 불균형 분류 평가 지표
패널 고정효과 모형
같은 단위(시군 등)를 여러 시점 관찰한 자료에서, 시간에 따라 변하지 않는 단위별 특성을 통제하고 변화의 관계를 추정하는 회귀모형
파인튜닝 (Fine-tuning)
사전학습된 모델을 특정 과제 데이터로 추가 학습시켜 그 과제에 맞추는 과정
FP16
16비트 부동소수점 형식. 모델 가중치를 파라미터당 2바이트로 저장, GPU 메모리 산정의 기준
API 게이트웨이
기관 공용 API 키를 한 곳에서 중계·배분하는 서버. 사용량·비용 추적, 모델 교체, 접근 통제 담당
GitHub Actions
GitHub 저장소에서 정해진 시각·사건에 스크립트를 자동 실행하는 서비스. 일일 수집·웹페이지 갱신에 활용
골드셋 (Gold Set)
연구자가 직접 정답을 붙인 검증용 표본. LLM·BERT 분류 정확도 측정의 기준
환각 (Hallucination)
LLM이 사실이 아닌 내용·출처·수치를 그럴듯하게 생성하는 현상
하이브리드 검색
의미검색(임베딩)과 키워드검색(BM25)을 결합한 검색. 의미 유사성과 정확한 용어 일치를 동시에 확보
증분 수집
전체를 다시 받지 않고 마지막 수집 시점 이후 새로 생긴 자료만 받는 방식
JSON
키-값 쌍으로 데이터를 표현하는 텍스트 형식. 대부분 API의 응답 형식
κ (코헨의 카파)
두 코더의 일치도에서 우연 일치를 뺀 지표. 0.6 이상 상당, 0.8 이상 매우 높은 일치로 흔히 해석
공공누리 (KOGL)
공공저작물 자유이용 허락 표시. 제1유형은 출처표시 조건으로 상업적 이용·변경 허용, 2~4유형은 상업 이용 금지·변경 금지 조건 추가
KV 캐시
LLM이 문장을 생성할 때 앞 내용의 계산 결과를 저장하는 메모리. 동시 사용자·긴 문맥일수록 커짐
LLM (대규모 언어모델)
대량의 텍스트로 학습해 문장을 이해·생성하는 수십억~수조 파라미터 규모 모델. GPT, Claude, Gemini, 엑사원 등
로컬 LLM
외부 클라우드가 아닌 기관 내부 서버에서 구동하는 언어모델. 자료가 외부로 나가지 않음
MCP (Model Context Protocol)
AI 도구가 외부 데이터·서비스를 '도구'로 호출하도록 하는 개방형 표준. Anthropic이 2024.11 공개
메타데이터
데이터에 대한 데이터. 작성기관·연도·문서유형·단위·수집 방법 등, 검색·결합·검증의 기반
국가망보안체계 (N2SF)
국가·공공기관 업무정보를 기밀(C)·민감(S)·공개(O)로 분류해 등급별로 보안통제를 차등 적용하는 체계. 기존 일률적 망분리의 대안
망분리
업무망과 인터넷망을 물리적·논리적으로 분리하는 공공기관 보안 방식. 외부 AI·클라우드 활용의 제약 요인
Ollama
개인 PC·소규모 서버에서 오픈 모델을 간단히 내려받아 실행하는 도구. 시범 운영에 적합
오픈 모델 (Open-weight Model)
가중치를 공개해 누구나 내려받아 자체 서버에서 구동할 수 있는 모델. 라이선스별로 상업 이용 범위 상이
평행추세 가정
DID에서 정책이 없었다면 두 집단의 추세가 같았을 것이라는 전제. 정책 이전 시기 추세 비교로 점검
양자화 (Quantization)
가중치를 16비트에서 8·4비트로 줄여 메모리와 연산을 절감하는 기법. 과제별 품질 저하 검증 필요
RAG (검색증강생성)
질문과 관련된 문서를 먼저 검색해 그 내용을 근거로 답변을 생성하는 방식. 최신성·출처 제시·환각 감소
RSS
사이트의 새 글 목록(제목·링크·날짜)을 XML로 배포하는 표준 형식. 키 없이 자동 수집 가능
스키마 (Schema)
데이터의 구조 정의. 변수명·자료형·단위·코드값 목록
SDMX
국제기구 통계 교환 표준 형식. OECD·IMF·세계은행 등 통계 API의 공통 규격
스킬 (Skill)
AI 에이전트가 필요할 때 불러 쓰는 작업 절차·지식 묶음(지시문 + 스크립트). 반복 업무의 표준화 단위
SSO (Single Sign-On)
한 번의 로그인으로 기관 내 여러 시스템을 이용하는 통합 인증
정적 HTML
서버 프로그램·DB 없이 미리 만든 HTML 파일을 그대로 게시하는 웹페이지. 유지보수·보안 부담 최소
서브에이전트
메인 AI 에이전트가 하위 작업을 맡기는 별도 에이전트. 독립된 맥락에서 작업 후 요약만 반환
에이전트형 코딩 도구
지시를 받아 코드를 작성·실행·수정하고 파일을 다루는 AI 도구. Claude Code, Codex, Gemini CLI 등
총소유비용 (TCO)
장비 구입비뿐 아니라 전력·냉각·감가상각·운영 인건비·교체 비용까지 합한 전체 비용
temperature
LLM 출력의 무작위성 조절 값. 0에 가까울수록 같은 입력에 같은 출력, 코딩·분류에는 낮게 설정
텍스트 마이닝
대량의 텍스트에서 주제·감성·개체·패턴을 계산적으로 추출하는 분석
텐서 병렬 (Tensor Parallelism)
한 모델의 연산을 여러 GPU에 나눠 처리하는 방식. 단일 GPU 메모리를 넘는 모델 구동에 필요
벡터DB
임베딩 벡터를 저장하고 유사도 검색을 빠르게 수행하는 데이터베이스
바이브코딩 (Vibe Coding)
자연어로 원하는 결과를 설명하고 AI가 코드를 작성·실행하게 하는 개발 방식. 사람은 설계·검수 담당
vLLM
다수 사용자의 동시 요청을 고처리량으로 처리하는 오픈소스 LLM 서빙 엔진
제로샷 (Zero-shot)
예시 없이 지시문만으로 모델이 과제를 수행하는 방식. 예시 몇 개를 주면 퓨샷(few-shot)
